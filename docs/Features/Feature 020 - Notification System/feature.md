# Feature 020 — Notification System

| Field | Value |
|-------|-------|
| **Domain** | SYS |
| **Status** | Not Started |

## Description

In-app notification system for informing employees and managers about important events: correction request status changes, leave request updates, shift changes, and system announcements. Uses a persistent notification store with read/unread tracking.

## Implementation Status

**NOT STARTED.** No notification infrastructure exists. Planned for Phase 3 of the improvement plan. Initial implementation will use polling-based in-app notifications; WebSocket-based real-time push can be added later.
