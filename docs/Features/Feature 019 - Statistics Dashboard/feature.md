# Feature 019 — Statistics Dashboard

| Field | Value |
|-------|-------|
| **Domain** | SYS |
| **Status** | Not Started |

## Description

A comprehensive statistics and analytics dashboard for managers to view attendance trends, identify patterns (frequent latecomers, absentees), and generate insights. Builds on top of the daily attendance summary (Feature 012) and provides visual charts and KPIs.

## Implementation Status

**NOT STARTED.** No statistics computation or dashboard exists. The current system only provides raw attendance event listings. This feature depends on Feature 012 (Daily Attendance Summary) being implemented first to provide aggregated data. Planned for Phase 3 of the improvement plan.
